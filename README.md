# NexTI Informática

Site institucional para uma empresa da área de informática, feito com HTML, CSS e JavaScript puros (sem dependências).

## Seções
- **Início** com terminal animado e contadores
- **Serviços**: manutenção, redes, segurança, desenvolvimento web, suporte remoto e nuvem
- **Sobre**
- **Planos** de suporte mensal
- **Dicas** de informática com filtro por categoria
- **FAQ**
- **Contato** com formulário validado

## Como usar
Abra o `index.html` no navegador, ou publique com o GitHub Pages
(Settings → Pages → branch de deploy, pasta raiz).

## Estrutura
```
index.html
css/style.css
js/main.js
```
